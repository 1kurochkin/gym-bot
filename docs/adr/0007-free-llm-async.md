# ADR-0007: Бесплатная LLM через OpenAI-совместимый API, вызов вне пути ответа, LLM возвращает черновик

Статус: accepted
Дата: 2026-10-12

## Контекст
Этап 5 начинается с конвертера программы из свободного текста; следом пойдут разбор подхода
свободным текстом и импорт истории. Владелец решил (12.10): LLM должна быть бесплатной, поэтому
DeepSeek из брифа (платный, хоть и дешёвый) отпадает. Бесплатные тарифы на 2026 год есть у
Google AI Studio (Gemini Flash и Flash-Lite), Groq (gpt-oss, Qwen), OpenRouter (модели `:free`)
и Cloudflare Workers AI. Лимиты у них часто меняются, а модели уходят с бесплатного тарифа без
предупреждения. Вызов LLM длится 5–30 с, а путь апдейта рассчитан на секунды: при таймауте
webhook Telegram повторяет апдейт (docs/architecture.md §3). Пользователей единицы, конвертаций —
несколько в неделю.

## Решение
- **Провайдер.** Основной — Groq с gpt-oss-120b на бесплатном тарифе: без карты, строгий
  JSON по схеме, быстрый ответ. Ключ Google AI Studio пока недоступен (ждёт подтверждения
  возраста), поэтому Gemini Flash — запасной провайдер, подключается, когда появится ключ;
  его плюсы — длинный контекст и выше лимит токенов в минуту. Оба вызываются через OpenAI-совместимый `/chat/completions` обычным `fetch`, без SDK и новых
  зависимостей. Провайдер, модель и ключ задаются переменными окружения
  (`LLM_BASE_URL`, `LLM_MODEL`, `LLM_API_KEY` и такие же с префиксом `LLM_FALLBACK_`), как и
  обещал ADR-0005. На 429 и 5xx основного провайдера бот один раз пробует запасной.
- **LLM возвращает черновик, а не программу.** Схема ответа нарочно маленькая: название
  программы, дни, в каждом упражнения (название, тип из пяти, подходы, повторения, заметка) и
  список строк, которые модель не поняла. id, ссылки на повторяющиеся упражнения, разминку и
  разминочные таблицы строит детерминированный код — тот же, что у редактора. Результат
  проходит полную валидацию программы. Маленькую плоскую схему бесплатные модели заполняют
  надёжнее, а всё, что можно проверить тестами, остаётся в ядре.
- **Вызов вне пути ответа.** Автомат выдаёт эффект «сконвертировать текст» и показывает
  «⏳ Разбираю программу…». Оболочка отвечает webhook сразу, вызов LLM идёт в фоне
  (`EdgeRuntime.waitUntil`). Его результат возвращается в автомат обычным событием («черновик
  готов» или «не получилось») через тот же цикл: загрузка → переход → транзакция → экран.
  Ядро остаётся чистым, Telegram не повторяет апдейт, а ответ на кнопки не ждёт LLM.
- **Учёт и лимит.** Каждый вызов — строка в новой таблице: пользователь, вид, провайдер,
  время, успех, токены, без текста. Отсюда дневной лимит на пользователя (по умолчанию 10
  конвертаций, у владельца без лимита) и метрики для выбора модели.
- **Подтверждение** — по ADR-0005: предпросмотр программы, [Сохранить] [Отмена]. При активной
  программе действует обычная замена с архивом. До «Сохранить» в БД ничего не пишется. После —
  переход в редактор, где результат можно доправить.

## Альтернативы
- DeepSeek (бриф) — платный; отпадает по решению владельца.
- Только Gemini — ключ пока недоступен. У Groq ограничение — 8 тыс. токенов в минуту на
  бесплатном тарифе, поэтому промпт держим коротким, а длинный текст программы упрётся в
  лимит; тогда поможет запасной Gemini.
- OpenRouter `:free` — 50 запросов в день без пополнения, состав бесплатных моделей
  меняется ежемесячно.
- Cloudflare Workers AI — 10 тыс. «нейронов» в день (от десятков до сотен вызовов в
  зависимости от модели), отдельный аккаунт и свой API, с бесплатного плана уходят модели.
- Локальная модель (Ollama) — Edge Function её не запустит, нужен свой сервер.
- Полная схема программы прямо в ответе LLM — схема большая (объединения, ссылки, таблицы
  разминки), бесплатные модели ошибаются в ней чаще; id и ссылки надёжнее строить кодом.
- Синхронный вызов с увеличенным таймаутом — апдейт висит до 30 с, растёт риск повторов
  Telegram и обрыва по лимиту функции.

## Последствия
- Новая таблица учёта вызовов LLM — миграция.
- В оболочке появляется фоновая задача и «событие из оболочки». Нужно отсечение устаревшего
  результата: пользователь мог уйти с экрана ожидания, и тогда результат молча отбрасывается.
- Бесплатный тариф Gemini разрешает Google использовать запросы для улучшения моделей. В текст
  программы не должно попадать личное; бот один раз предупреждает перед первой конвертацией,
  а README упоминает это по ADR-0005.
- Лимиты бесплатных тарифов не гарантированы: при исчерпании обоих провайдеров бот отвечает
  «LLM сейчас недоступна — пришли JSON или составь программу кнопками». Основные сценарии
  работают без LLM.
- Качество проверяется набором синтетических текстов программ с ожидаемыми черновиками.
  В `deno task check` модель подменяется фейком; прогон на живой модели — отдельной задачей
  с ключом, не в CI.
- Строка «LLM — DeepSeek» в стеке архитектурного гайда меняется на это решение после
  подтверждения.
