# Архитектурные решения (ADR)

Почему код и инфраструктура устроены именно так. Здесь суть каждого решения: открывай файл, только если нужны контекст, альтернативы и последствия.
ADR — снимок на дату принятия. Решение изменилось → новый ADR, у старого статус `superseded by ADR-000Y`; старые файлы не правят. Новый ADR — по [шаблону](0000-template.md) со статусом `proposed`, затем строка в эту таблицу (её сверяет тест в `deno task check`).
