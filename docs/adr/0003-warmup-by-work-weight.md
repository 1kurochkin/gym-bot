# ADR-0003: Разминка ступенями от рабочего веса, сингл только в базовых

Статус: accepted
Дата: 2026-09-28

## Контекст
Число разминочных подходов должно зависеть от того, насколько тяжёл рабочий вес, а не от упражнения.
Разминка — главная переменная для последующего сравнения программ, поэтому она детерминирована и логируется.

## Решение
Ступени по рабочему весу (< 135 / 135–224 / ≥ 225 lb) с процентами из программы (`warmupTiers`),
округление к ближайшему собираемому весу (при равенстве вниз). Перегрузочный сингл 105% — только при
`isBase: true` и не в дни на 70%. Для упражнений с допвесом — отдельная таблица от допвеса (сингл 110%).
Детали и контрольные примеры — `.specs/warmup.md` §6.2–6.3, фикстуры — `tests/fixtures/warmup-cases.json`.

## Альтернативы
- Фиксированная схема на упражнение — не учитывает рост весов, лёгкие дни получают лишние подходы.
- Расчёт через LLM — недетерминированно, не тестируется.

## Последствия
Пороги и проценты можно менять в программе без кода. Вариант разминки (`warmupVariant`) и ступень (`warmupTier`) пишутся в лог.
