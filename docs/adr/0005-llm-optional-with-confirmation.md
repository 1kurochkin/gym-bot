# ADR-0005: LLM опционален, любой результат LLM подтверждает пользователь

Статус: accepted
Дата: 2026-09-22

## Контекст
LLM (DeepSeek, фаза 2) удобен для разбора свободного текста и импорта истории, но ошибается.
Ошибка в логе тренировок незаметно портит данные для анализа.

## Решение
MVP работает без LLM. В фазе 2 ответы LLM — строгий JSON, валидируемый zod (один ретрай при невалидном).
LLM никогда не пишет в БД: результат показывается с кнопкой подтверждения. Провайдер — через
`LLM_BASE_URL` и `LLM_MODEL`.

## Альтернативы
- Автоматическая запись распознанного — быстрее, но ошибки попадают в данные.
- LLM с первого этапа — лишняя зависимость и сторонний провайдер для базового сценария.

## Последствия
Модули LLM загружаются динамически и не влияют на путь обработки кнопок. Данные уходят стороннему провайдеру — упомянуть в README.
