# Продукт

## 1. Обзор

**Продукт.** Telegram-бот, личный помощник в зале. Он хранит загруженную программу тренировок, подсказывает, какой день был последним, для каждого упражнения рассчитывает разминочную лесенку от выбранного рабочего веса, записывает каждый подход (вес × повторения) и комментарии, а по команде выгружает всё в Excel для последующего анализа (в том числе через LLM).

**Пользователь.** Владелец бота и знакомые, которых он пригласил ссылкой из бота (US-9). У каждого свои программа, настройки и история (все данные с `userId`).

**Главная цель данных.** После цикла 6–8 недель можно сравнить программы и понять, какая разминка и какая программа дают лучший результат. Поэтому записываем всё: разминочные и рабочие подходы, фактические веса, комментарии.

**Ключевые принципы**

- **Бот не тренер, а блокнот с калькулятором.** Решение о рабочем весе принимает пользователь. Бот показывает прошлый результат и комментарий к нему, но ничего не навязывает.
- **Минимум набора текста в зале.** Основной ввод через инлайн-кнопки; свободный текст остаётся запасным вариантом.
- **Единицы: фунты (lb)** во всём интерфейсе и в данных.
- **Язык интерфейса: русский или английский** (раздел «Язык интерфейса»).
- **Ни одна запись не теряется.** Каждый подход сохраняется сразу после ввода, незавершённая тренировка восстанавливается после закрытия чата.

## 2. Скоуп

**MVP (фаза 1)**

- Загрузка одной программы в формате JSON по шаблону из раздела 4 (файлом или текстом в чат).
- Ручной ввод стартовых рабочих весов по упражнениям (если истории нет).
- Тренировочный флоу: выбор дня, показ прошлого результата, выбор рабочего веса, расчёт и логирование разминки, логирование рабочих подходов, комментарии к упражнению и к тренировке.
- Подсказка «Прошлая тренировка: …» и выделение следующего по порядку дня.
- Отмена последнего подхода, пропуск и замена упражнения.
- Экспорт `.xlsx` по команде, файл приходит в чат.
- Настройки: вес грифа, набор блинов, язык.
- Интерфейс на русском и английском.

**Фаза 2 (LLM и удобство)**

- Импорт прошлых результатов одним сообщением через LLM с подтверждением распознанного.
- Разбор свободного текста в тренировке («185x8 последний тяжело»).
- Конвертация программы из свободного текста в программу через LLM (US-1, «Программа из текста»).
- Синхронизация с Google Sheets (опционально, в дополнение к экспорту).
- Корректировка разминки по прошлому комментарию: бот показывает комментарий и предлагает облегчённую схему.
- Кнопка [➖ Короче] на экране разминки (warmup.md §6.5).

**Вне скоупа (на будущее)**

- Несколько программ и переключение между ними (модель данных это уже поддерживает, UI нет).
- Аналитика и графики внутри бота.
- Автоматические рекомендации рабочего веса.
- Советы программы после рабочего подхода (доп. подход своим весом при малом допвесе, warmup.md §6.3): бот считает разминку и запоминает вес, а не ведёт по программе.
- Время отдыха: расчёт, показ, таймер, напоминания. Пока отдых целиком на пользователе.
- Открытый бот для всех: доступ только по приглашению владельца.
- Другие языки интерфейса (испанский и т. п.): добавляются словарём, когда понадобятся.

## 5. Пользовательские сценарии

**Команды**

| Команда | Действие |
|---|---|
| `/start` | Приветствие, статус: есть ли программа, прошлая тренировка, кнопка «Начать тренировку» |
| `/help` | Инструкция «Как пользоваться» (см. ниже) |
| `/workout` | Начать тренировку (то же, что кнопка) |
| `/program` | Загрузить или заменить программу, показать текущую |
| `/seed` | Ввести стартовые или прошлые результаты по упражнениям |
| `/export` | Прислать `.xlsx` по текущей программе |
| `/settings` | Часовой пояс, вес грифа, набор блинов, шаг веса по упражнениям, язык |
| `/undo` | Удалить последний записанный подход тренировки и вернуться к его вводу |
| `/history` | Прошлые тренировки: посмотреть, исправить или удалить подход, удалить тренировку |
| `/clear` | Очистить переписку с ботом (за последние 48 часов) и показать главный экран |
| `/cancel` | Прервать активную тренировку (с подтверждением, данные сохраняются со статусом `aborted`) |
| `/invite` | Только владелец: одноразовая ссылка-приглашение для нового пользователя |
| `/users` | Только владелец: кто пользуется ботом, отключить доступ |

**Инструкция для новых пользователей** (12.10). Сразу после онбординга часового пояса главный экран показывает часовой пояс, статус программы («Программы ещё нет — /program: составить кнопками, из текста или файлом .json.») и инструкцию; дальше на главном экране вместо неё строка «Как пользоваться — /help». `/help` показывает ту же инструкцию в любой момент и не сбрасывает текущий шаг (тренировка, ввод `/seed` продолжаются). Инструкция:

1. Первой строкой, на обоих языках: «🌐 Язык / Language: /settings → Язык / Language» — чтобы сменить язык мог и тот, кому достался не тот.
2. «1️⃣ Программа — /program»: составить кнопками, из текста (только если LLM настроена), файлом `.json`; править — /program → 📅 Дни и упражнения.
3. «2️⃣ Стартовые веса — /seed (можно пропустить)».
4. «3️⃣ Тренировка — /workout»: день → упражнение → рабочий вес → разминка → повторения после каждого подхода; «🏁 Завершить упражнение» — в меню дня, «🏁 Завершить тренировку» — сводка; ошибся — «← Назад» или /undo; прервать — /cancel.
5. «4️⃣ История — /history», «5️⃣ Настройки — /settings» (язык, часовой пояс, гриф, блины, шаг веса).
6. Только владельцу: «👑 Для владельца: /invite …, /users …».
7. Последней строкой: веса в фунтах (lb), команды — в меню рядом с полем ввода, подсказка — /help.

Полный текст на обоих языках проверяют сквозные тесты.

### US-1. Загрузка программы

1. `/program` показывает текущую программу (название, дни) или сообщает, что её нет, и предлагает прислать JSON или составить программу кнопками (см. «Редактор программы», п. 12).
2. Основной путь — **файл `.json`** (до 100 КБ); его можно прислать в любой момент, не только после `/program`. Текстом программа принимается после `/program`, если помещается в одно сообщение (4096 символов): программа владельца в отформатированном виде (≈ 4,3 тыс.) не помещается, Telegram разрежет её на части.
3. Бот валидирует. При ошибке — список ошибок с путями полей (не больше 10, остальные — числом). При успехе — краткая сводка: «5 дней, 10 упражнений. Дни: Фронтальный присед, Жим на наклонной, …».
4. Если активной программы нет — программа сохраняется сразу. Если есть — сводка новой, предупреждение «Текущая программа будет архивирована, история сохранится» и кнопки [Заменить] [Отмена]; до подтверждения ничего не сохраняется. Та же программа без изменений — «Программа не изменилась», ничего не сохраняется.
5. Повторная загрузка с тем же `id` программы создаёт новую версию (data-model.md → `programs`).
6. После сохранения бот предлагает пройти `/seed` для стартовых весов.

**Редактор программы** (08.10, расширен 12.10) — составить и править программу кнопками, без JSON. Вход — [📅 Дни и упражнения] на экране `/program`, когда программа есть; [🆕 Составить программу] — когда её нет.

1. **Дни** — название программы жирным и «Дни программы:». Кнопка на каждый день в порядке ротации, [➕ Новый день], [✏️ Название программы], [← Назад] → экран `/program`.
2. **День** — название жирным и упражнения списком «1. Жим на наклонной — 1×6–8» (у `reps_only` — «3 подхода»). Кнопки: упражнение на каждое, [➕ Новое упражнение], [➕ Из программы], [✏️ Название дня], [⬆️ Раньше] [⬇️ Позже] (место дня в ротации; у первого нет «Раньше», у последнего — «Позже»), [🗑 Удалить день] (нет, если день единственный или по нему идёт тренировка), [← Назад] → дни.
3. **Упражнение** — название жирным, «Тип: Штанга · Цель: 1×6–8». Кнопки [✏️ Переименовать], [🎯 Изменить цель], [⬆️ Выше] [⬇️ Ниже] (место в дне; у первого нет «Выше», у последнего — «Ниже»), [🗑 Убрать из дня] (нет, если упражнение в дне последнее: день без упражнений не бывает), [← Назад] → день.
4. **Названия** — упражнение, день и программа переименовываются одинаково: «Новое название для «Жим на наклонной» (до 60 символов):» (у дня — «…для дня «Жим»…», у программы — «…программы «…»…»), [← Назад] → экран, с которого пришли. Текст обрезается по краям; пустой или длиннее 60 символов — «Название — от 1 до 60 символов.», ввод заново. То же название — без сохранения. Сохранено — снова тот экран с «✅ Сохранено». История привязана к id: в старых записях остаются названия упражнения и дня на момент тренировки.
5. **[🗑 Убрать из дня]** — «Убрать «Жим на наклонной» из дня «Жим»? История упражнения сохранится.» [Убрать] [Отмена]. Убирается только из этого дня; если упражнение есть в других днях, его описание переносится в первый из них. Убрано из последнего дня — уходит из программы вместе с заметками и парами (`conditionalNotes`, `intensityPairs`), где оно упоминается. После — день с «✅ Убрано». Записи тренировок не трогаются; «восстановить удалённое» нет.
6. **[➕ Новое упражнение]** — три шага, [← Назад] на каждом — на предыдущий шаг (с первого — день):
   1. «Название нового упражнения (до 60 символов):» — правила как в п. 4.
   2. Тип: [Штанга] [Тренажёр / гантели] [Свой вес + допвес] [Только повторения] [Лёгкий вес] (`barbell`, `machine`, `weighted_bodyweight`, `reps_only`, `light_load`).
   3. Цель: «Подходы × повторения, например 3×8–12 или 1×6» (разделитель — x, х, ×, *; диапазон — через дефис или тире); для «Только повторения» — «Сколько подходов? Например 3 или 2–3». Подходов 1–20, повторений 1–100, начало диапазона не больше конца; иначе — «Не понял. …» с тем же примером.
   
   Упражнение добавляется в конец дня: id — первый свободный `ex_1`, `ex_2`, …; `isBase: false`; разминка — ступени у штанги, у остальных без разминки. После — день с «✅ Добавлено».
7. **[➕ Из программы]** — упражнения программы, которых нет в этом дне (в порядке ротации), кнопкой каждое и [← Назад] → день. Выбор добавляет его в конец дня ссылкой (`{"id": …, "ref": true}`), история общая. Нечего добавить — «Все упражнения программы уже в этом дне.»
8. **[🎯 Изменить цель]** — «Новая цель для «Жим на наклонной» (сейчас 1×6–8):» и пример, как в п. 6.3 (у «Только повторения» — только подходы), [← Назад] → упражнение. Цель общая для всех дней, где есть упражнение. Подписи подходов (`setTargets`) остаются, только если их столько же, сколько новый максимум подходов, иначе убираются. Та же цель — без сохранения; сохранено — упражнение с «✅ Сохранено».
9. **Порядок** — [⬆️ Раньше] / [⬇️ Позже] меняют день местами с соседним в ротации, [⬆️ Выше] / [⬇️ Ниже] — упражнение с соседним в дне. Сохраняется сразу, экран остаётся тем же с «✅ Сохранено». Ротация задаёт следующий день тренировки (US-2), порядок в дне — порядок в меню дня.
10. **[➕ Новый день]** — «Название нового дня (до 60 символов):» (правила как в п. 4), [← Назад] → дни. Затем «День «Спина»: добавь первое упражнение.» [➕ Новое упражнение] [➕ Из программы] [← Назад] → название дня. Дальше — п. 6 или п. 7; «Назад» с их первого шага — на этот экран. Пустой день не сохраняется: день появляется вместе с первым упражнением, в конце ротации, id — первый свободный `day_1`, `day_2`, …; после — день с «✅ Добавлено».
11. **[🗑 Удалить день]** — «Удалить день «Спина»? Упражнения, которых нет в других днях, уйдут из программы. История сохранится.» [Удалить] [Отмена] (→ день). Упражнения дня убираются по правилам п. 5, день — из программы и ротации. После — дни с «✅ Удалено». Тренировки по этому дню остаются в истории с прежним названием; если удалённый день был последним, следующим предлагается первый день ротации.
12. **[🆕 Составить программу]** — когда программы нет: «Название программы (до 60 символов):» [← Назад] → экран `/program`; затем «Название первого дня (до 60 символов):» [← Назад] → название программы; затем «День «…»: добавь первое упражнение.» только с [➕ Новое упражнение] и [← Назад], дальше — п. 6. Программа сохраняется вместе с первым упражнением: id `custom`, `units: "lb"`, ротация из одного дня, разминочные таблицы (`warmupTiers`, `addedWeightTiers`) — как в шаблоне (program-format.md). После — день с «✅ Программа создана», дальше обычный редактор.
13. Каждая правка сохраняется сразу новой версией программы (как загрузка JSON, п. 5), без подтверждения — кроме удаления (п. 5, п. 11). Тип упражнения, заметки, подписи подходов и схемы разминки в редакторе не меняются — только через JSON. Текст на экранах со списками кнопок игнорируется.

**Программа из текста** (12.10) — программу, записанную как угодно (заметки, сообщение тренера), разбирает бесплатная LLM (nfr.md → «LLM»). Кнопка [📝 Программа из текста] — на экране `/program`, если LLM настроена.

1. «Пришли программу текстом одним сообщением — как она записана у тебя или у тренера: дни, упражнения, подходы и повторения. …», пример структуры и предупреждение, что текст обработает внешняя нейросеть. [← Назад] → экран `/program`. Пример:

   ```
   Понедельник — Грудь и спина
   Жим лёжа (штанга) 3×8–10
   Подтягивания (свой вес) 3×6–8
   Жим гантелей на наклонной (гантели) 3×10–12
   Пресс (без веса) 3 подхода

   Среда — Ноги
   Присед (штанга) 4×5
   Жим ногами (тренажёр) 3×12–15
   Шея (лёгкий вес) 2×15
   ```

   Тип в скобках необязателен; если он есть, LLM берёт его, а не угадывает: штанга → «Штанга», тренажёр и гантели → «Тренажёр / гантели», свой вес → «Свой вес + допвес», без веса → «Только повторения», лёгкий вес → «Лёгкий вес». В название упражнения подсказка не входит.
2. Текст → «⏳ Разбираю программу… Обычно это занимает до 30 секунд.» Ответ приходит отдельным сообщением. Пока ждём, текст игнорируется; если ушёл на другой экран (`/program`, `/start` …), результат молча отбрасывается.
3. LLM возвращает черновик: название, дни, упражнения (название, тип, подходы, повторения, заметка) и строки, которые не поняла. Программу из черновика собирает бот по правилам редактора:
   - id дней `day_1`, `day_2`, …, упражнений `ex_1`, `ex_2`, …, программы — `custom`; разминка и разминочные таблицы — как у нового упражнения и программы с нуля (п. 6 и п. 12 редактора);
   - упражнение с тем же названием (без учёта регистра и пробелов по краям) в другом дне — ссылка на первое; повтор в том же дне отбрасывается; названия обрезаются до 60 символов;
   - подходы 1–20, повторения 1–100 (за пределами — к ближайшей границе, начало и конец диапазона упорядочиваются); повторения не указаны — 8–12 (кроме «Только повторения»);
   - день без названия получает название первого упражнения, день без упражнений отбрасывается; программа без названия — название первого дня.
4. **Предпросмотр:** «Вот что получилось: «Фулбади, 3 дня» — 3 дня, 6 упражнений. Дни: …», затем дни жирным и упражнения списком, как в редакторе; «Не понял — добавь вручную в редакторе:» со списком строк (не больше 10); при активной программе — «Текущая программа «…» будет архивирована, история сохранится.» Кнопки [💾 Сохранить] [Отмена]. До «Сохранить» в БД ничего не пишется.
5. **[💾 Сохранить]** — новая программа (замена — как загрузка JSON, п. 4–5), затем экран дней редактора с «✅ Сохранено». **[Отмена]** — «Отменено. Текущая программа осталась.»
6. **Не получилось:** LLM недоступна — «Нейросеть сейчас недоступна. Попробуй позже, пришли JSON или составь программу кнопками.»; черновик пустой или невалидный после одного повтора — «Не получилось разобрать программу. …». Кнопка [📝 Программа из текста] — попробовать снова.
7. **Лимит:** у участника не больше `LLM_DAILY_LIMIT` (по умолчанию 10) разборов за последние 24 часа — дальше «Лимит разборов программы за сутки исчерпан. …», LLM не вызывается. У владельца лимита нет.

Контрольный пример — черновик LLM и ожидаемая программа (tests/fixtures/program-draft.json): «Присед 3×5» в понедельник и «  присед » в пятницу → одно упражнение, в пятнице ссылка; «Тяга в наклоне» 3 × 10–8 → 3×8–10; «Жим гантелей сидя» 30 × 3 подхода без повторений → 3–20×8–12; день без названия → «Подтягивания с весом»; день «Отдых» без упражнений отброшен.

### US-2. Начало тренировки и меню дня (главный сценарий)

Тренировка — это **меню дня**: из него заходишь в упражнение, делаешь его и возвращаешься в меню. Порядок, добавление упражнения и завершение тренировки — только в меню: они касаются всей тренировки, а не отдельного упражнения.

```
Бот: Прошлая тренировка: Пн, 21.09 — Фронтальный присед.
     Выбери день:
     [▶ Жим на наклонной]   ← следующий по порядку, первым
     [Фронтальный присед] [Мёртвая тяга]
     [Брусья] [Подтягивания + тяга]
     [← Назад]
```

- Следующий день определяется по `rotation` от последней завершённой тренировки. Если пропущен день недели, бот всё равно предлагает следующий по порядку, а не по календарю.
- Выбор дня начинает тренировку и открывает меню дня. `/workout` при незавершённой тренировке младше 12 часов сразу открывает её меню; старше — закрывает её (`aborted`) и предлагает выбрать день.

**Меню дня**

```
Жим на наклонной · 02.10
✅ Жим на наклонной — 195 × 7, 195 × 6
◐ Пресс — 20 / 18
▫️ Шея: сгибания
▫️ Шея: разгибания

[▶ Шея: сгибания]
[✅ Жим на наклонной] [◐ Пресс]
[▫️ Шея: разгибания]
[➕ Добавить упражнение] [💬 Комментарий]
[🏁 Завершить тренировку] [← Назад]
```

- Упражнения дня по порядку программы и добавленные. Отметки: ✅ — нажато «Завершить упражнение», ◐ — начато (есть рабочие подходы), ▫️ — не начато.
- Первой кнопкой (▶) — первое не начатое упражнение по порядку дня: обычно выбор — одно нажатие.
- Упражнение ▫️ — начинается заново (US-3). ◐ и ✅ — открываются на вводе следующего подхода: можно дописать подход или через [← Назад] просмотреть и поправить прошлые (US-4).
- [➕ Добавить упражнение] — список упражнений программы, которых нет в меню, и [← Назад]; выбранное добавляется в меню и сразу открывается.
- [💬 Комментарий] — комментарий к тренировке (самочувствие, сон и т. п.).
- [🏁 Завершить тренировку] — сводка (US-5). Начатые, но не завершённые упражнения засчитываются: их подходы записаны. Если рабочих подходов нет ни одного, тренировка удаляется: «Подходов не было — тренировку не сохранял».
- [← Назад] — на главный экран; тренировка остаётся незавершённой, вернуться — `/workout`.

### US-3. Упражнение: рабочий вес → разминка → подходы

Все экраны упражнения начинаются с названия: «🏋️ **Жим на наклонной** 🏋️» и пустая строка. Название — жирным.

**Шаг 1. Рабочий вес**

```
🏋️ Жим на наклонной 🏋️

Цель: 1 рабочий × 6–8
Прошлый раз (15.09): 185 × 9 — выше диапазона
💬 «последний повтор с трудом, плечо ок»

Рабочий вес сегодня?
✍️ Или напиши свой вес.
[185] [195 (+10)] [175 (−10)]
[← Назад]
```

Кнопки строятся от прошлого рабочего веса с шагом, доступным для этого типа (для штанги 10 lb, см. раздел 6). Если истории нет — только ввод текстом. Отметка «выше диапазона» (9 > 8) — факт, без рекомендации. Вес нужен до разминки: разминка считается от него. [← Назад] — в меню. Для `reps_only` этого шага нет — сразу подходы.


**Шаг 2. Разминка**

```
🏋️ Жим на наклонной 🏋️

Разминка под 195 × 6–8:
1. 85 × 8    (по 20)
2. 135 × 5   (по 45)
3. 165 × 3   (по 60)
4. 205 × 1   (по 80) перегруз

[✅ Готово] [✏️ Изменить]
[💬 Комментарий] [⏭ Пропустить]
[← Назад]
```

- [✅ Готово] записывает все разминочные подходы по плану (`warmupVariant: full`); [⏭ Пропустить] — без разминки (`none`).
- [✏️ Изменить] проходит по подходам: «Разминка 2/4: 135 × 5 (по 45)» и [✅ Готово] [✏️ Изменить] [⏭ Пропустить] [← Назад]. [✏️ Изменить] просит написать, что сделал: «4» — повторения с плановым весом, «135/4» — вес и повторения; то же можно написать сразу. [← Назад] — к предыдущему подходу, его отметка снимается. Каждый подход записывается сразу; пропущенный — с отметкой `skipped`. После последнего — рабочий подход; вариант `custom`, если что-то отличалось, иначе `full`.
- [💬 Комментарий] — комментарий к разминке («устал после разминки»); в следующий раз он показывается над разминкой: «💬 Прошлый раз: устал после разминки».
- Вместо отметки разминки можно сразу написать рабочий подход.
- [← Назад] — к выбору веса (запись упражнения удаляется).

**Шаг 3. Рабочие подходы**

```
🏋️ Жим на наклонной 🏋️

Записал: 195 × 7, 195 × 6
Рабочий подход №3 — 195 × ? (по 75)
✍️ Или напиши: 7 — повторения, 185/6 — другой вес и повторения.
[5] [6] [7] [8]
[9] [10] [11] [12]
[💬 Комментарий] [← Назад]
[🏁 Завершить упражнение]
```

- Кнопки повторений — 8 чисел подряд: от прошлого подхода в этой тренировке (−3), для первого — от прошлого результата, без него — от начала диапазона.
- Повторения можно написать: **одно число — повторения с предложенным весом** («7» → 195 × 7); другой вес — вес и повторения («185x6», «185/6», «185 6»). Правила разбора — «Ввод свободным текстом».
- После подхода бот сразу ждёт следующий: подходов столько, сколько сделаешь, пока не нажмёшь [🏁 Завершить упражнение] (→ меню, упражнение ✅). Сверх `workSets.max` — с пометкой «сверх программы».
- Для штанги рядом с весом — вес на сторону. Для `weighted_bodyweight` вес — допвес: «+25». Для `reps_only` — только повторения и цель подхода («Подход 2 — 90% от отказа»).
- [💬 Комментарий] — свободный текст к упражнению (не к подходу); хранится и показывается в карточке в следующий раз.

### US-4. Исправления

- **[← Назад] ничего не удаляет из записанного**, а ведёт на предыдущий экран:
  - выбор дня, меню дня → главный экран (тренировка остаётся незавершённой);
  - выбор веса, список «Добавить упражнение» → меню; разминка → выбор веса (пустая запись упражнения удаляется); отметка разминки → предыдущая (её отметка снимается);
  - ввод подхода, пока подходов нет → разминка (её отметки снимаются) или выбор веса; у `reps_only` → меню;
  - ввод подхода №N → **просмотр подхода №N−1**: «Подход №2: 195 × 6» и [✏️ Изменить] [🗑 Удалить] [← Подход 1] [➡️ К подходу 3]. [✏️ Изменить] — написать, как было («7» или «185/7»), подход перезаписывается; [🗑 Удалить] — удалить подход; [➡️ К подходу N] — обратно к вводу. С просмотра подхода №1 [← Назад] — в меню;
  - комментарии → экран, с которого пришёл.
- **`/undo`** — удалить последний рабочий подход тренировки и вернуться к его вводу: «↩️ Удалил 195 × 7». Если у упражнения нет рабочих подходов, но отмечена разминка — удаляется разминка, бот показывает её снова. Нечего отменять — «Нечего отменять».
- Прошлые тренировки — `/history` (US-10).

### US-5. Завершение тренировки

[🏁 Завершить тренировку] в меню — сводка:

```
Тренировка завершена: Жим на наклонной, 22.09, 52 мин
Жим на наклонной: 195 × 7 (прошлый 185 × 9)
Пресс: 20 / 18 / 15
Шея: сгибания: не делал
[💬 Комментарий к тренировке] [Готово]
```

Упражнения дня без рабочих подходов — «не делал»; добавленные упражнения — в списке после упражнений дня. Комментарий к тренировке (самочувствие, сон и т. п.) — отдельное поле, важно для анализа.

### US-6. Ввод прошлых результатов (`/seed`)

MVP — пошагово по упражнениям активной программы.

1. Нужна загруженная программа (иначе — подсказка `/program`) и пройденный онбординг часового пояса.
2. Бот идёт по упражнениям программы в порядке дней (`rotation`), каждое — один раз, кроме `reps_only`: «Жим на наклонной (3/9). Последний рабочий результат? Напиши вес и повторения: 185x8, 185/8, можно с комментарием».
3. Если результат уже есть (прошлый `/seed` или тренировка) — показывается: «Сейчас: 185 × 8 (22.09)».
4. Кнопки: [Нет данных] — к следующему упражнению без записи; [Оставить] — если результат уже есть, не менять; [Закончить] — выйти, сохранённое остаётся.
5. Ввод разбирается как рабочий подход (раздел «Ввод свободным текстом»), но предложенного веса нет — нужен вес и повторения. Для допвеса — допвес: `+25x8`, `0x8` — свой вес. Текст после чисел — комментарий к упражнению.
6. Каждое упражнение сохраняется сразу после ввода: запись `source: manual_import` с одним рабочим подходом, дата — сегодняшняя локальная. Это не тренировка: в ротации дней и статистике тренировок не участвует.
7. В конце — сводка: сколько упражнений заполнено. `/seed` можно пройти ещё раз: новые записи станут «прошлым разом», старые остаются в истории.

Фаза 2: одно сообщение свободным текстом → LLM → таблица распознанного → [Сохранить] [Исправить]. LLM сопоставляет названия с `exerciseId` программы, нераспознанное показывается отдельно. Сохраняется только после подтверждения.

**«Прошлый раз» упражнения** — последняя по дате запись упражнения со статусом `done` (любой источник); из её рабочих подходов показывается лучший: больший вес, при равенстве — больше повторений.

### US-8. Настройки (`/settings`)

Экран с текущими значениями и кнопками разделов: [Часовой пояс] [Гриф] [Блины] [Шаг по упражнениям] [Язык] [Готово].

```
Настройки
Часовой пояс: UTC−4 · New York
Гриф: 45 lb
Блины: 5, 10, 25, 35, 45 lb → шаг штанги 10 lb
Шаг по упражнениям: 1 изменён
Язык: Русский
```

- **Часовой пояс** — тот же сценарий, что при онбординге (время или геопозиция); после сохранения — снова экран настроек. История не пересчитывается (data-model.md → «Часовой пояс»).
- **Гриф** — кнопки 45 / 35 / 33 (15 кг) lb или число от 5 до 100.
- **Блины** — переключатели 2,5 / 5 / 10 / 15 / 25 / 35 / 45 / 55 lb с отметкой ✓, [Сохранить] и [Назад]; хотя бы один блин. Блины меняют собираемые веса штанги и шаг допвеса — все расчёты пересчитываются сами (warmup.md §6.2).
- **Шаг по упражнениям** — список упражнений активной программы с весом, кроме штанги (у неё шаг задают блины): «Икры стоя — 5 lb (по умолчанию)». Выбор → кнопки 1 / 2,5 / 5 / 10 lb, число от 0,5 до 50 или [По умолчанию] — убрать переопределение. Порядок выбора шага — program-format.md → «Шаг веса».
- **Язык** — кнопки [Русский] [English] с отметкой ✓; выбор сохраняется сразу, экран настроек перерисовывается на новом языке.
- [Назад] в любом разделе — к экрану настроек, без изменений; [Готово] — главный экран.

### Кнопки и очистка чата

- Кнопки с текстом — списком, по одной в строку; числовые (повторения, вес, блины, гриф) — сеткой, чтобы не листать.
- `/clear` удаляет сообщения переписки — и бота, и пользователя — и присылает главный экран. Telegram даёт боту удалять сообщения только моложе 48 часов: более старые остаются (полностью очистить чат — «⋮ → Очистить историю» в самом Telegram). Данные — тренировки, программа, настройки — не трогаются; начатая тренировка продолжается через `/workout`.

### Команды, которых нет

На неизвестную команду бот отвечает «Не знаю такую команду» и списком доступных. Тот же список — в меню команд Telegram (`setMyCommands`), обновляется при каждой установке webhook и при запуске в режиме разработки. Меню — на двух языках: русское для пользователей Telegram с русским интерфейсом, английское для остальных.

### Язык интерфейса

- Языки: русский и английский. Пока пользователь не выбрал язык в `/settings`, бот говорит на языке интерфейса Telegram (`language_code`): `ru` — по-русски, всё остальное — по-английски.
- Выбор в `/settings` → [Язык] сохраняется в настройках и важнее языка Telegram.
- Переводятся только тексты бота. Названия упражнений, дней, заметки и подписи подходов берутся из программы как есть. Команды, формат ввода («185x8», «185/6») и единицы (lb) одинаковы на обоих языках.
- Числа и даты — по языку: по-русски «2,5» и «01.10», по-английски «2.5» и «Oct 1». Время — 24-часовое на обоих языках.
- Ошибки в файле программы тоже переводятся: путь к полю (`days[2].exercises[0].repRange.min`) одинаковый, пояснение — на языке пользователя.

### US-10. История тренировок (`/history`)

Исправить то, что заметил после тренировки: `/undo` работает только в текущей.

1. `/history` — завершённые и прерванные тренировки, новые сверху, по 8: кнопка «Ср 30.09 · Жим на наклонной» на каждую, [← Раньше] [Позже →]. Текущая незавершённая сюда не попадает (для неё — `/undo` и `/cancel`). Нет тренировок — «Тренировок пока нет.»
2. Тренировка → её сводка (рабочие подходы по упражнениям, как в US-5) и кнопки: [✏️ <упражнение>] на каждое упражнение с записью (кроме пропущенных), [🗑 Удалить тренировку], [← К списку].
3. Упражнение → «Жим на наклонной, 30.09» и рабочие подходы кнопками [1: 195 × 7] [2: 195 × 6], [➕ Подход], [← Назад].
4. Подход → «Подход 2: 195 × 6. Напиши, как было: 7 — повторения, 185/7 — вес и повторения.» и [🗑 Удалить подход] [← Назад]. Ввод разбирается как рабочий подход (раздел «Ввод свободным текстом») с весом этого подхода. После исправления — снова упражнение с «✅ Исправлено».
5. [➕ Подход] — «Напиши подход: 185/7» (без веса у упражнений только на повторения: «7»); подход добавляется последним.
6. Удаление подхода и тренировки — с подтверждением: «Удалить подход 2: 195 × 6?» / «Удалить тренировку 30.09 «Жим на наклонной»? Все её подходы удалятся.» [Удалить] [Отмена]. После удаления тренировки — список с «✅ Тренировка удалена».
7. Разминку и комментарии здесь не правим. «Прошлый раз», подсказка веса и следующий день считаются по истории — после правок пересчитываются сами.

### US-9. Приглашения и доступ (`/invite`, `/users`)

Владелец — тот, чей Telegram id указан в конфигурации бота (`ALLOWED_USER_IDS`, можно несколько). Остальные попадают в бот только по приглашению, без него бот молчит.

1. `/invite` — бот присылает одноразовую ссылку `https://t.me/<бот>?start=<код>`: «Ссылка-приглашение — перешли её. Сработает один раз, действует до 08.10.» Код случайный, подобрать его нельзя. Срок — 7 дней.
2. Новый человек открывает ссылку и жмёт Start: он становится участником, дальше обычный онбординг (часовой пояс), затем главный экран с инструкцией. Владельцу, который пригласил, приходит: «Иван (@ivan) присоединился по приглашению.»
3. Ссылка истекла, уже использована или с ошибкой — «Приглашение недействительно: оно истекло или уже использовано. Попроси новое.» Это единственный ответ человеку без доступа.
4. Участнику и владельцу код не нужен: `/start` с кодом работает как обычный `/start`, приглашение не тратится.
5. `/users` — список участников: «Иван (@ivan) — с 01.10» и кнопка [Отключить …] у каждого → «Отключить Ивана? Его данные сохранятся.» [Отключить] [Отмена]. Отключённый перестаёт получать ответы; программа и история остаются в базе. Вернуть — новым приглашением.
6. Для участника `/invite` и `/users` — неизвестные команды. В меню команд Telegram их видит только владелец.
7. Тексты — на языке пользователя: владельцу — на его языке, приглашённому до выбора языка — на языке Telegram.

### Ввод свободным текстом (фаза 2, частично MVP)

В MVP без LLM бот разбирает ввод подхода сам. Разбор зависит от контекста: какой вес бот предложил для этого подхода и какой у упражнения `loadType`.

| Ввод | Значит | Пример: бот предложил 180 × 6–8 |
|---|---|---|
| Одно целое число | Повторения с предложенным весом | `7` → 180 × 7 |
| `x` + число | То же, явно | `x7` → 180 × 7 |
| Вес и повторения через `x`, `х` (кириллица), `×`, `*`, `/` или пробел | Свой вес и повторения | `185x6`, `185/6`, `185 х 6`, `185 6` → 185 × 6 |
| Дробный вес — через точку или запятую | | `182,5x7` → 182,5 × 7 |
| Допвес (`weighted_bodyweight`) — со знаком `+` или без | Допвес на поясе; `0` — свой вес | `+25x8`, `25x8` → +25 × 8 |
| Текст после чисел | Комментарий к упражнению | `7 последний тяжело` → 180 × 7, комментарий «последний тяжело» |

- **Повторения** — целое число от 1 до 100. **Вес** — от 0 до 1500 lb.
- Для `reps_only` (пресс) вес не пишется: `20` или `x20` → 20 повторений; ввод с весом — ошибка.
- Если бот ещё не знает вес (первая тренировка без истории, пользователь выбрал «Ввести»), одного числа мало: бот попросит вес и повторения. Исключение — `reps_only`.
- Вес без повторений — ошибка «укажи повторения»: `+25`, дробное `182,5` или одно число больше 100 (`185` — это вес, а не 185 повторений).
- Несобираемый вес штанги принимается с предупреждением (§6.2).
- Не распознано — бот отвечает подсказкой с форматами. В фазе 2 такой ввод уходит в LLM со строгим JSON-ответом и подтверждением.
