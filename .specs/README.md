# Спецификации

Что делает бот и по каким правилам. Источник истины для поведения: меняешь поведение → сначала правка здесь, потом код, в одном коммите.
Как устроен код — в [docs/](../docs/README.md).

Читай только нужный файл. В начале каждого файла frontmatter: `title`, `brief_sections` (номера разделов исходного брифа), `updated`.

## Как добавить спецификацию

1. Новый файл `.specs/<тема>.md` с frontmatter (`title`, `brief_sections: []` для новых тем, `updated`).
2. Строка в таблицу «Индекс» выше.
3. Контрольные примеры из спеки — сразу в `tests/fixtures/`.

Исходный бриф (claude.ai/artifact/3QpNfXNacLX7ceg7mmDLab) после переноса больше не источник истины: правки вносятся здесь.
