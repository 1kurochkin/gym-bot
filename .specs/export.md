# Экспорт

## 8. Экспорт в Excel

`/export` формирует один `.xlsx` на программу: `{programId}_{YYYY-MM-DD}.xlsx`. Опция `/export all` — один файл по всем программам (колонка `program_id` позволяет их сравнивать). Главное требование: данные в «длинном» плоском формате, по одной строке на подход. Такой формат лучше всего понимают LLM и сводные таблицы.

**Лист `sets` (основной)** — одна строка = один подход

| Колонка | Пример |
|---|---|
| date | 2026-09-22 |
| iso_week | 2026-W39 |
| program_id | base6-5d |
| program_version | 1 |
| workout_id | w_… |
| day | Жим на наклонной |
| exercise_id | incline_press |
| exercise | Жим на наклонной |
| load_type | barbell |
| is_base | TRUE |
| intensity | high / low / пусто |
| set_kind | warmup / work / extra |
| set_index | 1 |
| planned_weight_lb | 165 |
| planned_reps | 3 |
| weight_lb | 165 |
| reps | 3 |
| skipped | FALSE |
| step_lb | 10 |
| warmup_tier | 2 |
| warmup_variant | full |
| e1rm_lb | только для work: Эпли `weight · (1 + reps/30)` |
| rep_range | 6–8 |
| above_range | TRUE, если reps > max |
| exercise_comment | «плечо ок» |
| warmup_comment | «устал после разминки» |
| workout_comment | «плохо спал» |

Комментарии дублируются в каждой строке подходов этого упражнения: так строка самодостаточна для анализа.

**Лист `exercise_summary`** — одна строка = упражнение в тренировке: дата, упражнение, интенсивность, лучший рабочий подход (вес × повторения), e1RM, тоннаж рабочих подходов, число разминочных подходов, вариант разминки, комментарии, дельта e1RM к прошлому разу.

**Лист `workouts`** — одна строка = тренировка: дата, день, статус, длительность, количество упражнений, комментарий.

**Лист `program`** — читаемая таблица программы (дни, упражнения, диапазоны, схемы разминки) и исходный JSON в одной ячейке, чтобы LLM видел контекст.

**Лист `README`** — описание колонок в 1–2 строки на каждую, чтобы файл можно было отдавать LLM без дополнительных пояснений.

Оформление: заголовки закреплены, автофильтр, числа — числами (не строками), даты — датами.

**Фаза 2: Google Sheets.** После каждой завершённой тренировки новые строки дописываются в таблицу Google (сервисный аккаунт, таблица расшарена на него). Структура листов та же. Ошибка синхронизации не блокирует бота: пишется в лог, повторяется при следующей тренировке.
