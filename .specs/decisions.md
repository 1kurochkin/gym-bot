# Решения

## 11. Решения и открытые вопросы

**Принято (22.09)**

- Блины 2,5 lb появятся позже: добавляются в `/settings`, всё пересчитывается само (6.2).
- Разминка строится ступенями от рабочего веса, а не от упражнения (6.2).
- Перегрузочный сингл — только в базовых упражнениях (`isBase`) и не в дни на 70%.
- Шаг веса настраивается по упражнению в `/settings`, чтобы смена тренажёра не требовала правки программы (раздел 4).
- Шея ведётся по весу блина с шагом 2,5 lb.
- Вес тела не отслеживается.
- Часовой пояс спрашивается при онбординге, хранится IANA-зона, показывается как `UTC−4 · New York` (раздел 7).
- 28.09: хостинг и БД — Supabase (Edge Functions + Postgres), защита от засыпания и бэкапы через GitHub Actions (раздел 3, ADR-0001).
- 28.09: бэкапы — ежедневный дамп БД файлом в личный чат Telegram (не в публичный GitHub) и схема в миграциях; автоматической еженедельной выгрузки `.xlsx` нет, только `/export`.
- 28.09: подтверждены ступени разминки от рабочего веса (6.2) и таблица для брусьев и подтягиваний (6.3).
- 28.09: архитектура кода — functional core / imperative shell, диалог как чистый конечный автомат, структура по фичам с правилом зависимостей, тулчейн Deno (раздел 13, ADR-0006).
- 28.09: часовой пояс при онбординге — по текущему времени пользователя (кнопки зон с этим смещением) или по геопозиции; ввод города убран (.specs/data-model.md → Часовой пояс).
- 30.09: время отдыха вне скоупа: бот его не считает и не показывает; поля `restSec` и `restBeforeWorkSec` убраны из формата программы (пример экрана разминки противоречил формуле линейного отдыха).
- 30.09: ввод подхода с учётом контекста: одно число — повторения с предложенным ботом весом; вес и повторения — свой вес (product.md → «Ввод свободным текстом»).
- 30.09: чередование 100/70 смотрит последнюю неделю, в которую пара выполнялась, а не строго прошлую: пропуск недели не сбивает чередование (§6.4).
- 30.09: программа загружается в основном файлом `.json`: отформатированная программа владельца больше лимита сообщения Telegram (4096). Замена активной программы — только после подтверждения кнопкой.
- 30.09: стартовые результаты (`/seed`) — записи `manual_import` без тренировки: `workoutId` у них пуст. «Прошлый раз» — лучший рабочий подход последней записи упражнения.
- 30.09: `/settings` — экран разделов; шаг по упражнениям — только для упражнений не на штанге (у штанги шаг задают блины).

**Открыто**

Открытых вопросов нет, спецификация готова к передаче агенту.
